# Client materials checklist

Send this to the client (or use it while waiting) so the portfolio can be completed without back-and-forth.

## Identity

- [ ] Preferred display name / brand name
- [ ] Role title in English (e.g. Screenwriter, Video Editor, Writer & Director)
- [ ] Short tagline (1 sentence)
- [ ] About paragraph (2–4 sentences, English)
- [ ] Headshot or logo (optional)
- [ ] Preferred colors / reference sites (optional)

## Work items (for each script or video)

- [ ] Title
- [ ] Type: `script` or `video`
- [ ] Function / role (e.g. Screenplay, Editor, Director)
- [ ] Category (e.g. Drama, Short Film, Reel, Treatment)
- [ ] Short description (1–2 sentences, English)
- [ ] Google Drive link (or file ID)
- [ ] Sharing set to **Anyone with the link → Viewer**
- [ ] Custom thumbnail (optional — otherwise Drive thumbnail is used)

## Contact

- [ ] WhatsApp number with country code (or full `wa.me` link)
- [ ] Discord invite or profile link
- [ ] Slack invite or contact link
- [ ] Email (optional)

## Launch

- [ ] Domain name (if already owned)
- [ ] Hosting preference (Vercel / Netlify / other)
- [ ] Any pages beyond Home / Work / About / Contact

## Suggested message to client

```
Oi! Pode me enviar estes materiais para eu montar o portfólio:

1) Nome de exibição, cargo/função em inglês, tagline e um texto curto About
2) Lista dos trabalhos (script ou vídeo), cada um com: título, função, categoria, descrição curta e link do Drive
3) Todos os arquivos do Drive com permissão “Anyone with the link” (Viewer)
4) Links de WhatsApp, Discord e Slack
5) Domínio/hospedagem se já tiver, e referências visuais se quiser

Pode mandar em texto mesmo, planilha ou pasta organizada. Assim que receber, começo a encaixar no site.
```
